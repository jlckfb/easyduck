# 网页控制

[English](../en/web-control.md) | **简体中文**

Python 3.9+ 标准库服务，默认端口 9527。服务通过 `/run/robotd.sock` 连接主控，不直接占用舵机串口。

板端由 `xgoduck-web.service` 启动，浏览器访问 `http://开发板IP:9527`。先点击“用网页控制”接管，再由用户开启行走。

- 左摇杆：前后行走、左右转向，松手停止；W/S 前后，A/D 转向，不提供横移。速度默认50%。
- 右摇杆：上下抬头低头、左右看；旁边两条滑杆控制颈部俯仰和歪头，独立按钮让头部回中。
- 坐下/起立、捡物按实际模型显示；网页不再提供翻滚和跳跃，接口也拒绝这两个动作。
- 按住鸣叫：复用手柄 wheee 声音，约0.35秒升至最大音量与张嘴幅度，松手立即停声并发送合嘴指令，连续点按每次从零开始。音频增益按强度平方变化，避免小幅张嘴时声音过响。失焦、隐藏或指令过期会停止鸣叫；旧版手柄未传音量时保留原来的音量。

默认站姿位于中间操作区底部；下方整行“详细状态”折叠显示关节数据和日志；断力始终可用。部署和离线测试不会替用户操作实物。

在仓库的 `web/` 目录执行：

```sh
python3 server.py --help
python3 -m unittest discover -s tests -v
node tests/controls.test.cjs
```

测试使用模拟 RPC。安装与启动步骤见[软件使用说明](software-guide.md)。

## Android App 遥控和对讲

1. 让标定完成的 EasyDuck 连 Wi-Fi，听它播报自己的 IP。手机连接同一个 Wi-Fi。
2. 打开 EasyDuck Android App，在“连接地址”输入 **鸭子播报的 IP**，按原来的方式接管遥控。App 会记住这个地址。鸭子换网或重新分配了 IP，就按最新播报修改。
3. 带麦克风的扩展板可点击“开启对讲”。首次使用时允许手机录音。按住说话，松开听鸭子周围的声音，App 请求使用手机大喇叭播放。

遥控和对讲在局域网内运行，Wi-Fi 可以没有互联网。对讲只使用鸭子的 IP，不用扫码或输入配对码。能够连接鸭子的局域网设备都能发起对讲，每次只允许一个对讲会话。

自己构建板端时，从仓库根目录在板端安装一次 [Android 对讲依赖](../../web/requirements-intercom.txt)，再按[软件使用说明](software-guide.md)安装和启动服务。板端需要可用的 Python pip。

```sh
sudo python3 -m pip install --target /opt/robot/xgoduck-web/intercom-deps -r web/requirements-intercom.txt
```

自己构建 APK 时，在安装 Android SDK 33 和 Gradle 8.7 的电脑上从仓库根目录执行：

```sh
gradle -p android :app:assembleDebug
```

输出为 `android/app/build/outputs/apk/debug/app-debug.apk`。同一份 APK 可以连接运行了 Android 对讲服务的不同鸭子。

## 语音对讲

带麦克风的扩展板可用遥控页的“语音对讲”。用设备提供的 HTTPS 域名打开遥控页，填写连接设置所用的账号和密码，点“开启对讲”，然后允许浏览器使用麦克风。按住按钮说话，鸭子的喇叭会播放你的声音。松开后，手机恢复播放鸭子周围的声音。退出对讲或离开页面后，录音会停止。

语音在手机和泰山派之间传输，运行时不保存录音。扬声器由对讲和原有提示音共用。板端配置公开受信任的 HTTPS 证书和域名后，普通 HTTP 遥控页会显示 HTTPS 入口。手机使用系统内置的证书信任，直接打开即可。

## RGB 状态指示灯

遥控页的“状态指示灯”区域可开关 WS2812B 灯、调节亮度和电量呼吸速度，也能查看当前灯效。默认开启，亮度为 70%，电量呼吸速度为最快（5 档）。速度设置只用于绿、黄、红三种电量呼吸灯。

| 灯效 | 含义 |
| --- | --- |
| 绿灯呼吸 | 电量 ≥ 50% |
| 黄灯呼吸 | 20% ≤ 电量 < 50% |
| 红灯呼吸 | 电量 < 20% |
| 蓝灯慢呼吸 | 行走所需的标定数据尚未保存或校验未通过。数据有效后恢复电量显示，机械限位待确认仍可在标定页查看。 |
| 白灯短闪两下 | 手柄已连接 |
| 白灯长亮约 1 秒 | 手柄已断开 |
| 紫灯反复双闪 | 主控持续报故障，或状态灯服务持续读不到主控状态。可在“详细状态”查看日志。 |
| 红灯连续快闪 | 已触发[低电量保护](low-battery.md)，动作暂时锁定。 |
| 熄灯 | 指示灯已关闭，或暂时无法获取有效电量。 |

灯开启时，低电保护优先显示，其次是持续故障、手柄连接或断开提示、待标定，最后是电量。低电保护解除后，红灯停止快闪，显示当前适用的状态。

## 页面切换

页面顶部可切换到连接设置或实物标定台。入口使用当前主机的设置服务（默认端口 80，读取 `/etc/easyduck/setup.env` 中的 `EASYDUCK_SETUP_PORT`），普通页面切换先检查当前连接，正常时保留当前地址；USB 拔出后使用本页此前读取到的 Wi-Fi 地址继续切换。没有无线地址时显示连接提示。相同主机上的登录会话可以继续使用；跨 IP 访问或设置服务重启后仍需重新登录。设置服务的安装见 [连接设置说明](connection-setup.md)。

离开控制页会释放网页控制连接。进入标定需确认机器人已放稳，随后停止正式控制并请求断力；标定退出会检查草稿、运动及力矩状态，释放串口后恢复正式服务，不会自动上力或运行策略。通信或供电故障时，页面切换成功不代表实物已全部断力。
