# 低电量自动坐下

本功能在 robotd 内执行，网页和手柄无需保持打开页面来判断电量；原有控制心跳、IMU、总线失联断力规则仍然有效。

## 配置

板级配置 `config/board/robotd.toml` 已设置：

```toml
[safety]
low_battery_sit = true
low_battery_voltage = 6.2
battery_empty_shutdown = false
```

通用默认值保持关闭，电压默认 6.2V；仅泰山派板级配置显式启用。触发条件是有效、非零的平滑电压小于或等于门槛。电压来自舵机总线，约每秒更新，平滑时间约 10 秒；电压显示不是电芯容量的精确测量。

## 触发后的行为

- 播放一次低电量提示音，并立即抢占行走、拾取、翻滚、起身恢复及页面/手柄控制；不等待音频结束。
- 已上力且模型和传感器可用时，使用坐下模型（xgoduck使用posture，而非倒地恢复sitstand），归零其他动作输入。普通控制心跳和控制权交接不会取消坐下。
- 坐下模型至少运行2秒，随后腿部实际速度低于0.15 rad/s、实际与目标角误差小于0.15 rad持续0.5秒后断力。6秒仍未完成则按超时断力，日志记录原因，不声称坐下成功。
- 模型不可用或传感器失效时断力；断力写入失败持续重试。原本断力的机器人不会自动上力。
- 触发后拒绝网页/手柄动作、默认站姿、启用、模式切换和普通音效，直到重启主控。手动断力始终可用；电压回升不解除锁定。
- 不自动关闭系统。低电量处理期间不接受关机请求或执行旧的自动关机判定。

## 音效库

音效库版本已升为 6，`sounds ensure-bank` 会重新生成包含 `low_battery/low_battery_a.wav` 的音效库，继续使用原机器种子。不需要联网或新依赖。

正式部署时需要一起更新 robotd、sounds 和板端配置，并运行原有音效库更新流程。仅更新 robotd 而未更新音效库会导致提示音缺失。音频设备或文件异常不阻止坐下，不等待音频播完才控制关节。

## 验证范围

离线检查覆盖电压门槛、一次触发、无效读数、坐下状态选择、动作衔接、提示音抢占，以及低电量不关机、不主动上力。实物坐下效果和扬声器播放仍须在后续明确允许部署后验证。
