# 仓库维护检查

[English](README.md) | **简体中文**

## 职责

开发侧的仓库文档检查，与部署脚本和机器人程序分开。当前检查器读取本地文件并报告文档完整性问题，不连接机器人。

## 文件结构

| 文件／目录 | 职责 |
| --- | --- |
| [check_docs.py](check_docs.py) | UTF-8／LF、语言配对、语言切换、章节／示例、引用与导航检查 |
| [../docs/AGENTS.md](../docs/AGENTS.md) | 文档术语与更新规则 |
| [../AGENTS.md](../AGENTS.md) | 仓库范围与协作边界 |

## 调用与数据流

1. 维护者在根目录运行 python3 tools/check_docs.py，或用 --root 指向隔离的源码快照。
2. 检查器遍历相关 Markdown，解析有效本地引用，比较语言结构／示例；确定性检查失败时返回失败状态。

## 边界与修改注意

- 它不验证外部网站可达性、翻译含义、实物动作或已部署服务。
- 检查保持少依赖、只读；一次性迁移脚本与证据留在仓库外，本脚本不会暂存或提交。
