# 控制页浏览器资源

[English](README.md) | **简体中文**

## 职责

由 web/server.py 提供的静态控制界面，处理用户输入、控制权／状态展示及连接清理；不独立决定舵机目标，也不运行动作模型。

## 文件结构

| 文件／目录 | 职责 |
| --- | --- |
| [index.html](index.html) | 页面控件、状态区和导航 |
| [app.js](app.js) | 摇杆／键盘／按钮、WebSocket 心跳、释放与回中 |
| [style.css](style.css) | 响应式布局与交互外观 |
| [../server.py](../server.py) | 静态资源与网关接口提供方 |

## 调用与数据流

1. 用户事件转换为网页接口请求与连接心跳，Python Gateway 再把允许的意图发送给 robotd。
2. 主控状态更新控件，失焦、输入过期和导航按客户端流程清理或释放网页输入。

## 边界与修改注意

- 不能在这里另加直接控制舵机的链路，前端命令范围要与后端校验一致。
- 翻译文档不会自动翻译这些界面字符串，模拟交互检查也不能证明硬件行为。
