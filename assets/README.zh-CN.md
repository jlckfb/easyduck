# 仓库展示素材

[English](README.md) | **简体中文**

## 职责

供中英文 README 共用的展示素材。实物照片和动作动图用于项目展示，与运行时网格、策略模型及生成的机器人音效分开。

## 文件结构

| 文件／目录 | 职责 |
| --- | --- |
| [images](images) | 预留的机器人／扩展板实物照片 |
| [demos](demos) | 两个根 README 共用的五张本地动作动图 |
| [../README.md](../README.md) | 英文展示使用方 |
| [../README.zh-CN.md](../README.zh-CN.md) | 中文展示使用方 |

## 调用与数据流

1. 根 README 使用仓库相对路径引用素材，由 GitHub 从同一仓库提供文件。
2. 两种语言共用素材字节、分别填写说明；机器人服务不加载这些展示文件。

## 子目录

| 目录 | 说明 |
| --- | --- |
| [demos](demos/README.zh-CN.md) | 实物动作展示动图 |
| [images](images/README.zh-CN.md) | 实物照片位置 |

## 边界与修改注意

- 除非另有要求，原始 MP4 保留在仓库外；实物展示应保留真实拍摄内容，不能用生成图替代硬件证据。
- 保留 GIF 动画、比例及准确说明。GitHub 会过滤内联 CSS，当前展示使用表格／图片属性和本地引用。
