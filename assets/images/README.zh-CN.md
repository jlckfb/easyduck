# 实物照片位置

[English](README.md) | **简体中文**

## 职责

用于保存机器人、扩展板与接线的实物照片。当前尚未放入实物照片。

## 文件结构

| 文件／目录 | 职责 |
| --- | --- |
| [.gitkeep](.gitkeep) | 让 Git 保留尚为空的预留目录 |
| [../../README.md](../../README.md) | 英文照片区域使用方 |
| [../../README.zh-CN.md](../../README.zh-CN.md) | 中文照片区域使用方 |

## 调用与数据流

1. 加入真实照片后，再在两个 README 选定的展示位置添加相应的相对图片引用。
2. 同一照片由两种语言共用，分别填写说明；本目录没有运行时调用方。

## 边界与修改注意

- 预留目录不代表已有照片，真实文件加入前不要添加会产生破图的图片标签。
- 检查照片是否露出凭据或私有标定，不在照片目录混放代码、模型或原始视频。
