# 原始许可证正文

[English](README.md) | **简体中文**

## 职责

保存记录中相关组件使用的原始第三方许可证正文。它们是参考／授权记录，不是可执行模块，也不是给整个仓库统一指定一种许可证；中英文目录介绍指向同一套权威原文。

## 文件结构

| 文件／目录 | 职责 |
| --- | --- |
| [GPL-2.0-only.txt](GPL-2.0-only.txt) | GNU GPL 第 2 版原文 |
| [GPL-3.0-or-later.txt](GPL-3.0-or-later.txt) | 配合记录的 or-later 声明使用的 GNU GPL 第 3 版正文 |
| [../LICENSE](../LICENSE) | 根目录项目许可证正文 |
| [../NOTICE](../NOTICE) | 署名与来源记录 |
| [../THIRD_PARTY_NOTICES.md](../THIRD_PARTY_NOTICES.md) | 按组件记录的来源与许可范围 |

## 调用与数据流

1. 仓库声明将代码／资源与记录的条款关联，阅读正文时要结合这些来源记录。
2. deploy/install.py 将许可记录复制到应用许可目录，随安装文件一起提供。

## 边界与修改注意

- 保留原文和署名，不用翻译后的新条款替换原文，也不能从一个文件名推断所有组件适用相同许可。
- 声明或哈希检查不会授予尚未明确的再分发权利，本介绍不改变已记录的组件许可。
